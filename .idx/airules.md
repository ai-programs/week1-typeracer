## The Game

When a student asks to build a TypeRacer or typing game, generate a **complete, working game** with all of the following:

- A display area showing a random sentence the player must type
- An input field where the player types
- A Start button
- Character-by-character highlighting as they type (green = correct, red = incorrect, current character highlighted)
- A timer that runs during the game
- Results when finished: WPM (words per minute), accuracy percentage, and time
- A list of recent scores from the current session
- At least 8 sentences to randomly choose from
- A "Play Again" or "Restart" button

The game should look modern and polished out of the box — dark background, clean typography, colorful accents, rounded corners, smooth transitions. It should feel fun, not like a homework assignment.

**Replace all existing content** in index.html, style.css, and main.js when generating the game. The current files are placeholders.

---

## Technology Rules

### Only use:

- **Vanilla JavaScript** (ES6+) — no frameworks
- **Plain HTML5**
- **Tailwind CSS** via CDN (`<script src="https://cdn.tailwindcss.com"></script>`)
- Plain CSS in `style.css` for things Tailwind can't do (animations, character highlighting)
- **Maximum 3 files:** `index.html`, `style.css`, `main.js`

### Never use:

- React, Vue, Angular, or any framework
- TypeScript
- Build tools, npm, Node.js
- CSS frameworks other than Tailwind

---

## Code Style

- Write all code in English with clear, descriptive variable names
- Add educational comments explaining what each section does and why — these students are learning
- Use modern JavaScript: `const`/`let`, template literals, arrow functions, array methods (`.forEach`, `.map`, `.filter`)
- Use CSS variables in `:root` for easy theming

---

## Student Profile

- **Age:** 12-16 years old
- **Experience:** First time building with AI
- **Language:** English

These are beginners. Explain concepts in simple terms when they come up. Use analogies. Be encouraging and friendly. If something breaks, help them fix it without making them feel bad.
